# 확인한 실행 환경

2026-10-11에 현재 `.venv`의 설치 메타데이터와 저장된 실험 메타데이터를 읽어 확인했다. 새 환경 생성, 의존성 설치, 학습·추론은 실행하지 않았다.

| 항목 | 확인한 값 |
|---|---|
| OS | Windows 11, AMD64 |
| Python | 3.14.8 |
| NumPy | 2.5.3 |
| pandas | 3.0.6 |
| Matplotlib | 3.11.2 |
| WFDB | 4.3.1 |
| PyTorch | 2.13.0+cu130 |
| pip | 26.2.1 |
| 기존 학습 장치 | NVIDIA GeForce RTX 5070, CUDA |
| 최종 test 평가 장치 | CPU |

`requirements.txt`는 실제 코드에서 직접 import하는 외부 패키지 다섯 개를 고정한다. 테스트는 표준 라이브러리 `unittest`를 사용한다. 전이 의존성을 모두 고정한 lock 파일은 아니다.

PyTorch의 공개 버전은 `2.13.0`, 현재 설치된 빌드 태그는 `+cu130`이다. 설치 파일에는 공개 버전을 지정했으므로 설치 플랫폼에 따라 빌드가 달라질 수 있다. CPU 추론에도 PyTorch가 필요하며 GPU를 쓰려면 해당 장치에 맞는 PyTorch 빌드와 드라이버가 필요하다. 새 컴퓨터에서의 설치 성공과 실행 결과 일치는 아직 검증하지 않았다.

체크포인트 메타데이터는 모델 구조·소스 해시를 검사한다. 배포를 위해 기존 Python 소스를 자동 포맷하거나 줄바꿈을 변환하지 않는다. 환경·장치가 바뀌었을 때 bitwise 재현성은 보장하지 않는다. 상세 실험 환경과 소스 해시는 공유용 결과 JSON에도 남아 있다.
