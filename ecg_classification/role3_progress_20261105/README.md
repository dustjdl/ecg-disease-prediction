# 3번 질환 분류: 오류 분석 및 개선 실험 결과

## 이번 작업의 결론
C 모델(실제 Lead I + 재구성 11유도)의 CD 분류 약점을 분석하고 두 방법을 비교했다. 단순 평균 앙상블은 CD와 전체 macro F1이 낮아졌다. CD 양성 가중치 완화는 오탐을 줄였지만 실제 CD를 더 많이 놓쳤고 CD F1도 소폭 낮아졌다. 두 설정 모두 이번 결과만으로 기존 모델을 대체하지 않는다.

## 수행 범위
질환 분류 담당(3번)의 기존 결과 분석과 실험만 포함. 새로운 데이터·라벨 기준 확정 또는 통합 프로그램 작업은 수행하지 않았다. 기존 라벨 유지. **v2 라벨 재학습 결과가 아니다.**

## 1. 기존 결과의 반복 오류 분석
기존 저장 예측에서 검증 C 모델 CD F1은 세 seed 평균0.4983이었다. 검증 CD 양성16건 가운데 평균7건을 놓쳤다.
- ECG234: 원본1AVB 코드, B는3회 모두 탐지·C는3회 모두 놓침.
- ECG520·633: 원본LAFB 코드, A·C는3회 모두 놓침·B는3회 모두 탐지.
- ECG524: B·C 모두 놓침. 재구성만의 문제로 단정할 수 없음.
- ECG544: 코드 기반 CD=0이지만 원본 보고서 대조가 필요한 표현이 있음. 라벨 및 기존 FP 평가 유지, 추가 확인 대상으로 기록.
case_review에는 원본/재구성 파형3장과 Lead I 제외 유도별 오차를 포함했다. 별도 학습된 분류 모델끼리의 비교여서 재구성 오차가 분류 오류의 원인이라는 인과 결론은 내리지 않는다.

## 2. 단순 앙상블: 저장 예측으로 실행
C seed42/43/44의 점수 평균, 임계값도 기존 세 임계값 평균으로 고정. 검증96건.
- CD F1: 개별 모델 평균0.4983 -> 앙상블0.4571
- 전체 macro F1:0.6903 ->0.6749
이번 규칙은 채택하지 않음. 모든 앙상블 방법이 효과 없다는 의미는 아님.

## 3. CD 가중치 비교: 사용자 컴퓨터에서 실제 학습 완료
완료 화면과 업로드된 validation_by_seed.csv, validation_summary.csv를 분석했다. 총2조건×3seed×5라벨=30행. 혼동행렬과 F1 및 요약 평균을 재계산해 일치 확인. 가중치 파일·실행 로그 전체를 이 패키지에 수집한 것은 아니므로 학습 전체의 독립 재현 검증은 아니다.
- 입력C, 5개 라벨, seed42/43/44,각40epoch,총6회학습
- 기존 neg/pos 양성 가중치 중 CD만 제곱근으로 완화:3.975 ->약1.994
- 두 조건 모두 원래 가중치의 검증BCE가 가장 낮은 epoch 선택
- 동일한 검증F1 임계값 선택 규칙
- 테스트 forward pass와 성능 계산 없음
- 이번 실행 baseline도 같은 환경에서 새 학습. 역사적 baseline0.4983과 이번0.5098은 구분해야 함.

| CD 지표(3seed 평균) | 이번 baseline 재학습 | CD 가중치 완화 |
|---|---:|---:|
| Precision |0.59349|0.71242|
| Recall |0.64583|0.41667|
| F1 |0.50979|0.50343|
| FP |13.6667|4.0000|
| FN |5.6667|9.3333|

전체 macro F1:0.694326 ->0.695447(절대차+0.001121,약+0.112퍼센트포인트). 명확한 개선의 증거로 보지 않음. 소수점 건수는 같은 기록에 대해3개모델의 건수를 평균한 값이다.

## 해석과 한계
CD를 덜 예측하면서 FP와 recall이 모두 낮아졌다. 훈련 가중치 변경 후 다른4라벨의 점수도 변했다. 이 실험은 질환별 임계값도 각 학습 결과에 맞춰 다시 선택한 전체 절차 비교이며, 고정 임계값에서 가중치만의 효과를 측정한 것은 아니다. CD를 개선 대상으로 고르고 모델·임계값을 선택한 검증 데이터를 다시 평가한 탐색적 결과이다. 성능 향상이나 임상 활용성을 입증하지 않는다. 3seed는 동일96명의 반복 학습이며288명의 독립 데이터가 아니다. 기존 테스트 결과가 이미 공유된 프로젝트이므로 향후 최종검증은 새로운 미사용 자료를 확보하거나 사전에 고정한 평가계획이 필요하다.

## 실행 방법
scripts 폴더에서 PyTorch,numpy,pandas,scikit-learn,matplotlib가 설치된 Python으로 실행한다. 기존 ecg_for_classification.npz를 지정한다. 출력 폴더는 존재하지 않는 새 경로를 사용한다.
```powershell
python .\run_cd_weight.py --npz "C:\실제데이터경로\ecg_for_classification.npz" --output .\results\CD_weight_trial2
```
원본 cohort.csv의 기존 라벨만 사용. 새 라벨을 넣는 기능은 없음. 모델 학습 산출물은 사용자의 results/CD_weight_trial1에 보관되어 있으며 이 패키지에는 포함하지 않았다.
