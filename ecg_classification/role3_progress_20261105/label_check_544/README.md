# ECG 544번 CD 라벨·예측 검토 결과

## 검토 결론
현재 실험의 코드 기반 라벨에서는 CD=0이므로, CD=1 예측은 기존 평가에서 거짓 양성(FP)으로 유지한다. 다만 원본 보고서에 코드 목록과 대조가 필요한 전도 관련 표현이 있어 **추가 확인 대상**으로 기록한다. 라벨 오류나 모델의 임상적 정답을 확정하지 않는다.

## 확인한 원본
- ECG ID: 544
- 환자 ID: 13772
- 원본 fold: 9 / validation
- SCP 코드: `{'IMI': 100.0, 'LVH': 100.0, 'ISC_': 100.0}`
- 원본 보고서: `sinustachykardi hypertrofi av vÄnster fÖrmak vÄnster el-axel ospecifikt skÄnkelblock vÄnster kammarhypertrofi`

보고서의 `ospecifikt skÄnkelblock` 표현과 코드 목록을 대조할 필요가 있다. 보고서 표현만으로 CD 라벨을 자동 추가하지 않았다. 이 검토는 원본 텍스트와 코드·예측의 대조이며 의료적 재판독이 아니다.
