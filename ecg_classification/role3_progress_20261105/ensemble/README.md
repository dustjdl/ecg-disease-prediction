# C 분류 모델 앙상블 예비 비교

## 방법
기존 C 입력(실제 I+재구성11유도) 모델 seed42,43,44의 저장된 점수를 ECG ID와 라벨로 연결해 동일 가중치 평균. 라벨별 판정 임계값은 기존 세 임계값의 산술평균으로 고정. 새로운 임계값 탐색 없음. probability >= threshold이면1. 검증 데이터 eligible=True 96건, 5라벨 사용. 미분류4건은 기존 정책대로 제외. 기존 라벨·모델 파일 변경 없음. 테스트 데이터는 이번 비교에 사용하지 않음.

## 비교 대상과 결과
기준값은 세 개별 모델 지표의 평균이며, 앙상블은 동일96건에 대한 한 번의 결합 예측 지표이다. 학습을 추가한 결과가 아니다.
- CD F1: 0.4983 -> 0.4571
- CD 놓친 건수: 개별 평균7건 -> 앙상블8건 (CD 양성16건)
- 전체5라벨 macro F1: 0.6903 -> 0.6749
- MI F1: 0.6884 -> 0.7059

이번 고정 규칙의 단순 평균 앙상블은 CD 및 전체 macro F1에서 개선을 보이지 않았다. 따라서 기존 모델을 대체하는 개선안으로 채택하지 않는다. 모든 앙상블이 효과 없다는 결론은 아니다. AUROC/AUPRC 및 질환별 결과는 CSV 참고.

## 한계
기존 모델 선택과 임계값 결정에 이미 사용한 검증 데이터의 탐색적 비교이다. 독립 성능 향상의 증거가 아니며 새 데이터 또는 사전 고정한 절차에 따른 추가 검증이 필요하다. 이번 결과를 보고 임계값을 반복 조정한 뒤 같은 데이터의 점수를 일반화 성능으로 보고하면 안 된다.

## 다음 실험 제안
CD 성능이 낮은 이유를 더 구분하기 위해, 기존 가중치 BCE와 양성 가중치를 완화한 BCE를 동일 학습 조건에서 비교하는 실험을 설계할 수 있다. 이는 아직 실행하지 않았으며, 앙상블 결과만으로 가중치가 원인이라고 확정하지 않는다.
