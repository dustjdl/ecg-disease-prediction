# PTB-XL 100 Hz: 1번 담당 라벨 정책 v2.0 (제안, 새 학습 정답)

작성일: 2026-11-03  
상태: **팀 승인 전 연구용 파생 라벨. 임상 판독 변경이 아님.**  
정책 ID: `role1_v2.0_proposed_2026-11-03`

## 분석 데이터와 불변 조건

- 입력: `ecg_reconstruction/reports/role2_summary_20261031/tables/ecg_labels_all_1000.csv`, `ecg_labels_analysis_998.csv`, `code_details.csv`, `dataset_split_998.csv`, `label_review.csv`
- `ecg_reconstruction/prepare_dataset_1000.py`는 데이터 **준비 코드**이며 의료용 원본 데이터 파일이 아님. 100 Hz 파형 데이터는 이번 보고서 ZIP에 포함되지 않음.
- 기존 1,000개 중 품질 검사에서 제외된 ECG ID 421, 710은 기존 기준대로 998개 분석 목록에 없음. 삭제하거나 원본 선정 결과를 바꾸지 않음.
- 기존 분할 train 798 / validation 100 / test 100, 기록/환자 ID, `scp_codes`, 측정 파일 경로, 진단 코드와 기존 원본 `NORM, MI, STTC, CD, HYP` 값을 **변경하지 않음**.
- 새 기준은 `target_v2_` 접두사 열 또는 명시적으로 분류 실험용이라고 이름 붙인 별도 CSV에만 표현함.

## v2 규칙: 우선순위 순서대로 적용

| 규칙 | 조건 | v2 처리 | 원본 처리 | 이유 |
|---|---|---|---|---|
| 1 | NORM/MI/STTC/CD/HYP 모두 0 | `supervised_eligible_v2=0`, 다섯 `target_v2_*`와 `binary_target_v2`를 **빈 값**으로 둠 | 998개 전체 및 파형 분석에 유지 | 5개 진단군 중 어느 것도 해당하지 않는다고 해서 정상이라고 확정할 수 없음 |
| 2 | MI, STTC, CD, HYP 중 하나라도 1 | 해당 질환 라벨(복수 포함)은 1 유지, `target_v2_NORM=0`, `binary_target_v2=1` | 기존 코드와 NORM 값 유지 | 질환이 있으면 학습 정답의 NORM은 정상 상태를 뜻하도록 일관되게 정의 |
| 3 | NORM만 1 | `target_v2_NORM=1`, 질환 4개는 0, `binary_target_v2=0` | 원본 유지 | v2의 정상은 지정된 진단군 기준에서 질환 양성이 없는 경우 |
| 4 | 진단 SCP likelihood = 0.0 | 유효 진단 코드를 삭제하지 않고 `unknown_diagnostic_likelihood=1` 및 코드 목록 기록 | SCP 코드/값 변경 없음 | 0.0은 PTB-XL에서 '진단 확신도가 기록되지 않음'을 뜻함. 음성(질환 없음)이 아님 |
| 5 | NORM과 질환 동시 1 | 규칙 2에 따라 **v2의 NORM만 0**; 각 질환은 그대로 | 원본 혼합 진단 유지 | 학습 표적의 의미 충돌을 제거하는 연구 정책이며, 실제 진단 정정이 아님 |
| 6 | 추정 결과 및 분할 검증 | v2 데이터와 분포 계산, patient 교집합 0, 기존 CSV SHA256 일치 필수 | 기존 train/val/test 변경 없음 | 이전 재구성 결과 및 v1 분류 실험의 재현성 보호 |

- 5개 진단군에 속하지 않는 8개(PACE 5개, AFLT 3개)는 **998개 재구성 집합에서는 유지**, **5개 진단군 지도학습/평가에서는 제외**한다. `ecg_labels_v2_classifier_998.csv`에서는 기존 분류 코드와의 호환성을 위해 이 8개의 5개 분류 열만 0으로 두고, 명시적 마스크 `supervised_eligible_v2=0` 및 `target_v2_*` 공란을 함께 저장한다. **0 다섯 개를 실제 음성 정답으로 취급하지 말 것.**
- 다른 진단 코드의 likelihood가 0인 것은 무조건 검토 대상이 아님. 본 분석은 `code_details.csv`에서 `diagnostic=1`인 0.0 코드만 14개 검토 대상으로 표시했다.
- 기존 분류 실험은 NORM+질환 동시 1을 허용한 v1 정책으로 완료되었다. v2 적용 이후에는 동일 990개에서 **새 모델을 학습·재평가**해야 한다. 기존 체크포인트/임계값/지표를 v2 결과로 표시하지 않는다.
- ‘정상’은 선택된 5개 진단군에 대한 **연구용 정상**을 뜻하며 모든 임상 이상 가능성이 없음을 보증하지 않는다.

### Train / Validation / Test: v2 지도학습 대상의 진단별 개수

| 진단군 | Train / 796 | Validation / 96 | Test / 98 |
|---|---:|---:|---:|
| NORM | 434 | 48 | 47 |
| MI | 136 | 28 | 19 |
| STTC | 165 | 26 | 26 |

질환 간 복수 라벨 허용으로 열 합계가 각 분할 대상 수를 초과할 수 있음. HYP 테스트 8개는 매우 작으므로 지표 해석에 주의. MI의 비율은 Train 17.09%, Validation 29.17%로 차이가 있음. 원래 분할을 유지해 기존 결과와 비교 가능하게 하며, 성능 개선을 위해 테스트 분할을 다시 고르지 않음.

## 검토 대상 처리 원칙

- 16개 혼합: `target_v2_NORM=0` 제안, 질환 4개는 원본 유지, `review_required_v2=1`.
- 8개 미분류: 5진단군 지도학습 제외, 원본·재구성 기록 보존. 진단군 추가(AFLT 등)는 **다른 정책 버전**에서 시행.
- 14개 SCP 0.0: 기존 코드가 유효한 진단인지 `code_details.csv`와 원본 보고서(실제 임상 보고서는 이 ZIP에 포함되지 않음)를 참고하여 별도 검토. 이번 v2에서는 삭제하지 않음. 추후 민감도 분석 별도 실시.
- 같은 기록이 혼합과 0.0 모두 해당되는 경우 2개이므로 **16+8+14=38은 중복 계산**, 고유 검토 기록 36개임.
- 36개 검토표에는 담당자/승인자/결정일을 기록할 빈 칸이 있음. 자동으로 승인된 것으로 표기하지 않음.
