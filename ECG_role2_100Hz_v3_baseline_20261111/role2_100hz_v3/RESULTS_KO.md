# 100Hz 기존 CNN 기준 실험 결과

## 이번에 실행한 내용
실제 Lead I을 입력해 실제 나머지 11유도를 예측하는 기존 기본 CNN을 3개 seed로 학습했습니다. v3 라벨은 질환군별 검증 분석에만 사용했습니다.

학습 798개, 검증 100개. 테스트 100개는 평가하지 않았습니다. 각 30 epoch이며, 최저 검증 MSE의 가중치를 선택했습니다.

| seed | 선택 epoch | 검증 MSE (mV²) | 검증 MAE (mV) | pooled RMSE (mV) |
|---|---|---|---|---|
| 42 | 16 | 0.039456 | 0.096458 | 0.198634 |
| 43 | 22 | 0.039195 | 0.096035 | 0.197978 |
| 44 | 24 | 0.039191 | 0.096521 | 0.197967 |

3 seed 평균 MSE: 0.039281 ± 0.000151 (seed 간 표준편차).
3 seed 평균 MAE: 0.096338 mV.

## 해석
이 결과는 U-Net·500Hz와 비교하기 위한 100Hz 기본 CNN 기준값입니다. 새로운 구조/해상도와의 비교가 아직 없으므로 성능 개선을 주장하지 않습니다. v3 기본 진단 라벨은 v2와 같고, 진단 라벨은 재구성 손실에 사용하지 않으므로 v3 재라벨링에 따른 재구성 개선 실험도 아닙니다. 기존 Dilated 모델 결과와 혼동하지 마세요.

모델과 epoch 선택에 사용한 검증 데이터의 결과입니다. 최종 일반화 성능이나 임상적 유효성을 뜻하지 않습니다. 추가 비교를 준비하면서 테스트셋을 반복 사용하지 않도록 이번 실행에서는 테스트 추론을 생략했습니다.

## 제공 파일
- code/: 원본 기본 CNN, 학습·분석 및 그래프 코드
- data/: 기존 NPZ에서 실제 파형과 메타데이터만 추린 무손실 파일. 생성 예측 파형은 제외
- labels/: 제공받은 v3 라벨·정책 문서
- results/baseline/: 설정, 체크포인트 3개, 학습 기록, 검증 예측·상세 지표·요약표 및 그림

원 실험은 기존 ecg_for_classification.npz를 사용했습니다. 패키지의 실제 파형 전용 NPZ는 관련 배열이 원본과 같음을 검증했으나, 압축 내용이 다르므로 파일 SHA-256은 원본과 다릅니다. verification.json에 별도 해시를 기록했습니다.
